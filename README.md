# Actividad-Nomina-Quincenal

# Descripción del programa
Este programa permite registrar empleados, seleccionar tipo de contrato y cargo, calcular salario regular, horas extras, incentivo de transporte, deducciones y salario neto. Además, muestra un resumen general con la cantidad de empleados registrados y los totales acumulados de la nómina. Basado en la actividad de Programación Básica de Nómina Quincenal.
